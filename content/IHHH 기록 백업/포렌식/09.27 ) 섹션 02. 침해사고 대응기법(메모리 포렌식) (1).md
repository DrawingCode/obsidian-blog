### <volatility 명령어>

- imageinfo : 메모리 덤프 운영체제 식별

	💡 volatility_2.6_win64_standalone.exe -f .\cridex.vmem imageinfo
    
- 프로세스 리스트 출력 명령어
    
    pslist: 시간 순서대로 출력
    
    psscan: offset 순서대로 출력(메모리 위치 기준) > 숨긴 프로세스를 볼 수 있음
    
    pstree: PID, PPID 기반으로 구조화
    
    psxview: pslist, psscan 포함한 결과 한 눈에 볼 수 있음
    

	 💡 volatility_2.6_win64_standalone.exe -f .\cridex.vmem --profile=WinXPSP2x86 pslist > pslist.log

    
- 네트워크 분석
    
- netscan
    - windows 7 이상
    - tcp, udp / IPv4, IPv6 지원
    - port 상태 보여줌: Listening(열림), Established(통신 중), Closed(닫힘)

        ![[ip 분석.jpg]]
    
    user = 10.1.1.20
    
- CMD 분석
    
    - cmdscan, consoles: 콘솔에 입력한 값/출력한 값 확인 가능 > 출력 방식이 다르므로 둘 다 써주어야 함
    - cmdline : 프로세스 실행 시 인자값 확인 가능
- 파일 분석 및 메모리 덤프
    
    - filescan: 메모리 내의 모든 파일 리스트 출력 > offset 추출 가능

	💡volatility_2.6_win64_standalone.exe -f .\Target1-1dd8701f.vmss --profile=Win7SP0x86 dumpfiles -Q 0x000000003df31038 -D files -n
	
- dumpfiles: 파일 덤프. offset 혹은 프로세스를 전달할 수 있음
        - 만약 프로세스 전달 시 해당 프로세스가 사용하는 모든 파일을 다 추출해 줌
        
	💡 dumpfiles -Q -n -D [PATH]
	💡 dumpfiles -p [PID] -D [PATH]


- 프로세스 세부 분석
    - memdump : 특정 프로세스가 사용하는 메모리 영역 덤프
        → strings로 의미 있는 문자열 추출
        💡 memdump -p [PID] -D [PATH]
        💡 strings.exe .\dumps\[FILENAME] > [OUTNAME].log
        
    - procdump: 프로세스의 실행 파일 추출 (filescan에서의 파일과 다를 수 있음)
        
        💡 volatility_2.6_win64_standalone.exe -f .\cridex.vmem —profile=WinXPSP2x86 procdump -p [PID] -D [PAT
        
- 악성 프로그램 식별
    - virustotal
    - Windows Defender (기본 프로그램 알림)
