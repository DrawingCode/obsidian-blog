### 이론

**<Windows Artifacts (윈도우 아티팩트)>**
: 윈도우가 가진 특유 기능과 그것을 구현하는데 필요한 요소, 윈도우의 사용자가 수행하는 활동에 대한 정보를 보유하고 있는 개체

- 생성증거: 프로세스, 윈도우 시스템에서 자동으로 생성한 데이터
- 보관증거: 사람이 기록한 데이터
- 종류(레지스트리, $MFT, LNK, JumptList 등)
- 생각할 것
    - 사용자의 행위에 따라 어디에 어떤 정보가 저장되는지
    - 컴퓨터가 어떤 원리로 동작하는 것인지

**Registry** - 윈도우 아티팩트 중 가장 양이 많고 복잡함

: 운영체제와 응용 프로그램 운영에 필요한 정보를 가진 계층형 데이터베이스

운영체제 및 응용 프로그램의 설정 정보, 서비스의 데이터 등을 기록

부팅, 로그인, 서비스 실행, 프로그램 실행, 사용자 행위 등 모든 활동을 기록

> 윈도우 시스템 전체적인 범위에 관여

ex) 시스템 표준 시간(TimeZone), 시스템 정보, 사용자 계정 정보, 환경변수 정보, 자동실행 프로그램, 응용프로그램 실행 흔적, USB 연결 흔적, 접근한 폴더 정보

<레지스트리 조회(Regedit - 레지스트리 편집기)>

- 루트 키 설명
HKEY_CLASSES_ROOT (HKCR) : 파일 확장자 연결 정보, COM 객체 등록 정보
HKEY_CURRENT_USER (HKCU) : 현재 시스템에 로그인한 사용자의 프로파일 정보
HKEY_LOCAL_MACHINE (HKLM) : 하드웨어, 소프트웨어 설정 및 기타 환경 정보
HKEY_USERS (HKU) : 전체 유저에 대한 프로파일 정보
HKEY_CURRENT_CONFIG (HKCC) : 시스템 시작 시의 하드웨어 정보

**< $MFT >** $는 시스템 파일이라는 뜻

MFT (Master File Table)

: NTFS 파일시스템에서 파일, 디렉터리를 관리하기 위한 구조

(NTFS는 윈도우가 쓰는 파일 시스템)

하나의 파일이나 디렉터리가 하나의 MFT 엔트리를 가짐 > 이들의 집합이 $MFT

**< MFT 엔트리 >**

- 파일의 이름, 생성/수정/변경시간, 크기, 속성 등 보유
- 파일의 디스크 내부 위치, 시스템 경로 등을 알 수 있음

> > 하나의 파일 당 그 파일에 대한 모든 정보를 지닌 MFT 엔트리가 있고, 이 엔트리들을 모은 것이 $MFT

**< $LogFile >**

- 저널링(Journaling): 데이터 변경을 디스크에 반영하기 전 행위를 기록하는 것

데이터를 쓰는 도중 문제가 생기면 데이터가 손실되므로 그 전에 데이터의 내용과 시간, 위치를 기록해 놓는 것.

추후 오류 복구에 활용하기 위함

- 트랜잭션(Transaction): 업무 처리의 최소 단위
    
    파일이나 디렉토리 생성, 수정, 삭제, MFT 레코드 변경 등
    
- $LogFile: 메타데이터의 트랜잭션 저널 정보
    
    메타데이터란? 말 그대로 범data. 데이터의 변경, 삭제 등 데이터에 대한 데이터
    
    저널링에서 데이터를 처리할 때 기록하고 있는 정보들의 집합
    

**< $UsnJrnl >**

- 파일이나 디렉터리에 변경 사항이 생길 때 이를 기록하는 로그 파일
- 복원이 아닌, 파일 작업이 있었다는 사실을 확인하기 위함.
- 시간 순서대로 엔트리 저장, 기본 크기는 32mb / 용량이 차면 덮어쓰이는 방식

**< 바로가기(LNK) >**

- Windows Shortcut
- .Lnk 확장자
- 바탕 화면
    - %UserProfile%\Desktop
- 시작메뉴
    - %ProgramData%\Microsoft\Windows\Start Menu
    - %UserProfile%\Appdata\Roaming\Microsoft\Windows\Start Menu
- 최근 실행
    - %UserProfile%\Appdata\Roaming\Microsoft\Windows\Recent

참고로 %UserProfile% == :C\User\Desktop (나는 Pro) 예약어

%ProgramData% == 얘도 C에 있는 ProgramData로 가는 예약어

**\<Jumplist\>**

- 최근에 사용한 파일, 폴더에 빠르게 접근할 수 있는 구조
- 종류
- Automatic : 운영체제가 자동으로 남기는 항목
- Custom : 응용프로그램이 자체적으로 관리하는 항목

~exe 파일(응용프로그램)과 관련된 아티팩트들~

**\<Prefetch\>**

- 응용프로그램의 빠른 실행을 위해 RAM 내부에 존재하는 파일
- 응용프로그램을 실행할 때 생성
- 실행 파일의 이름, 경로, 실행 횟수, 마지막/최초 실행 시간을 저장해 빠르게 실행하도록 도움
