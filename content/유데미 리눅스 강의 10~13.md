# 10. Linux vs Unix

unix = 솔라리스, H-0UX, AIX 같은 운영체제에 사용됨 / 지원되는 파일체제가 훨씬 적음/ 특정 하드웨어에만 설치 가능
linux = 레드햇, 센토스, 데비안 등에서 사용 / 다양한 하드웨어에 설치 가능


# 11. Linux Flavors

linux flavors = distribution = distros

1. ubuntu : 가장 인기있는 배포판 중 하나. debian 기반
2. Fedora : Redhat 지원
3. Debian
4. RedHat (RHEL) : 기업 위해 개발
5. CentOS : 무료 오픈 소스 클론 RHEL 
6. archlinux : 단순함, 커스텀으로 유명 - manjaro(더 단순화된 버전)
7. openSUSE
8. Linux Mint : 우분투 기반, 더 디테일한 데스크톱 경험 제공
9. gentoo : 사용자가 소스 코드에서 소프트웨어 컴파일
10. slackware : 단순함, 미니멀리즘 
11. alpine : 컨테이너식 애플리케이션에서 인기
12. kali linux : 포렌식, 침투 테스트를 위한 배포판

일자리를 위해서라면 센토스 추천. 기업 전체에서 대부분 사용됨


# 12. Linux Users

누가 리눅스를 사용하는가?
- 개발자: 광범위한 프로그래밍 언어와 도구지원
- 교육기관 
- 정부기관 : 특히 안정성과 보안이 필요한 분야
- 엔터프라이즈, 비즈니스 : 서버와 데스크톱, 데이터 센터에 사용
- 클라우드, 웹 서버 
- 슈퍼컴퓨터와 연구 시설 
- 통신 및 네트워크 
- 미디어, 엔터테인먼트 - 영화, 미디어 산업, 그래픽, 애니메이션 제작



# 13. Linux vs Windows

Linux
- open source
- free
- GNOME, KDE, XFCE, GUI 등 다양한 인터페이스 사용 가능 
- console is at the very core of Linux
- apt, tum, pacman 등의 packge manager 사용
- 다른 운영체제보다 보안상 안전
- 안정적, 효율적 - 재부팅하지 않고 몇 달, 몇 년동안 실행 가능
- XFS, Btrf 등의 파일 시스템 사용

Windows
- proprietary of microsoft
- standard GUI
- command prompt, powershell 
- standalone executable(.exe)
- 윈도우의 large user 중 일부이기 때문에 멀웨어의 타겟이 될 가능성 있음
- 실행하고 시간이 지나면 느려지는 경향 있음 
- NTFS, FAT32 파일 시스템 사용
